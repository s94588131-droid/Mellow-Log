# Mellow Log

GitHub Pages用の静的ファイル一式です。

## 公開方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html`, `manifest.webmanifest`, `.nojekyll` をリポジトリのルートにアップロードします。
3. GitHubのリポジトリ画面で `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にします。
5. `Branch` を `main` / `/root` にして保存します。
6. 数十秒から数分後、表示されたURLをiPhoneのSafariで開きます。
7. Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように起動できます。

## データ保存について

記録データはSafariのローカルストレージに保存されます。端末やブラウザを変える場合は、アプリ内の「iCloud用バックアップ」でJSONを書き出し、移行先でインポートしてください。
